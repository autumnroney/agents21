How the viral score works (0–100). Each video is compared with the other results from the same platform in this search, so 50 is a typical result and 100 is the best. Speed counts about 70%: views per hour, adjusted for age so brand-new posts aren’t over-rewarded and long-running hits aren’t under-rewarded. Engagement counts about 30%: likes, comments (×2) and shares (×3) per view, pulled toward the platform’s typical rate when a video has few views.

If a platform doesn’t report likes, the score uses speed only. If the post date is unknown, speed counts as average. With fewer than 20 results from a platform, a fixed scale is used instead. Confidence is low when data is missing or a video has under 1,000 views.
